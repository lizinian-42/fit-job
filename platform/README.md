# 苍穹平台交付目录

本目录用于保存可进入版本控制的苍穹平台资产。

| 目录/文件 | 内容 |
| --- | --- |
| `app-manifest.example.yaml` | 应用、环境和模型编码模板，不含凭据 |
| `model-inventory.md` | 模型清单、编码和实现状态 |
| `exports/` | 平台允许导出的模型或配置资产 |
| `kwc/` | 目标平台官方脚手架生成的 KWC 源码 |
| `java/` | 苍穹官方模板生成的 Java 插件/服务源码 |
| `ai/` | Agent、RAG、工具协议、提示词和评测资产 |

## 事实源规则

- 在线低代码模型以苍穹平台为运行时事实源；
- 仓库中的模型清单和导出物用于审查、协作和恢复；
- KWC/Java 源码以仓库为事实源，并通过平台构建或部署验证；
- 不提交租户密钥、Token、密码、真实学生数据和本机发布缓存。
