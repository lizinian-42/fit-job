# Fit Job 苍穹模型清单

> 模型编码为建议基线；首次在目标苍穹环境创建后，应以平台实际编码为准并同步更新本文件。

## 表单模型

| 编码 | 名称 | 主要字段/职责 | 状态 |
| --- | --- | --- | --- |
| `fit_student_profile` | 学生画像 | 学籍摘要、求职意向、技能、偏好、帮扶标签 | 待创建 |
| `fit_resume` | 简历与版本 | 简历文本、结构化内容、目标岗位、诊断状态 | 待创建 |
| `fit_job` | 岗位库 | 企业、JD、技能、地点、薪资、有效期 | 待创建 |
| `fit_job_match` | 岗位匹配记录 | 六维分、总分、推荐解释、准备建议 | 待创建 |
| `fit_internship_application` | 实习申请 | 学生、岗位、申请材料、审批状态 | 待创建 |
| `fit_internship_log` | 实习日志 | 日期、内容、工时、风险标记 | 待创建 |
| `fit_tripartite_review` | 三方评价 | 学生、企业、辅导员评价与结论 | 待创建 |
| `fit_employment_destination` | 就业去向 | 去向类型、行业、地区、薪资区间 | 待创建 |
| `fit_policy` | 就业政策 | 标题、地区、适用人群、正文、来源、有效期 | 待创建 |

## 服务模型

| 编码 | 名称 | 实现 |
| --- | --- | --- |
| `fit_resume_diagnose` | 简历诊断服务 | Agent + Java 输入输出校验 |
| `fit_job_match_service` | 六维岗位匹配服务 | Java 评分 + Agent 解释 |
| `fit_interview_training` | 面试训练服务 | Agent + 训练记录落库 |
| `fit_policy_qa` | 政策问答服务 | RAG + 来源引用 |
| `fit_risk_evaluate` | 实习风险评估服务 | Java 规则 |
| `fit_dashboard_aggregate` | 驾驶舱聚合服务 | Java/报表聚合 |

## 流程模型

| 编码 | 名称 | 节点 |
| --- | --- | --- |
| `fit_internship_approval` | 实习申请审批 | 学生提交 → 辅导员审核 → 院系审核 → 企业确认 → 归档 |
| `fit_internship_exception` | 实习异常处理 | 风险触发 → 辅导员处理 → 院系复核 → 关闭 |

## 权限模型

| 角色 | 数据范围 | 主要操作 |
| --- | --- | --- |
| 学生 | 本人数据和公开岗位/政策 | 编辑档案、诊断、匹配、申请、日志、训练 |
| 辅导员 | 所负责学生与申请 | 审核、跟进、预警处理、评价 |
| 企业 HR | 本企业岗位与候选人 | 岗位维护、录用确认、企业评价 |
| 院系管理员 | 本院系汇总与配置 | 权限配置、报表、流程复核、质量分析 |

## 报表模型

| 编码 | 名称 | 核心指标 |
| --- | --- | --- |
| `fit_employment_dashboard` | 就业驾驶舱 | 就业率、签约率、行业、地区、薪资、帮扶覆盖 |
| `fit_internship_quality` | 实习质量报表 | 申请转化、转正、日志完整度、评价、风险 |
| `fit_ai_effectiveness` | AI 能力效果报表 | 诊断使用、匹配点击、训练完成、政策命中 |
